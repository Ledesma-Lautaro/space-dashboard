<objective>
Scaffold the Next.js 16 App Router project into this greenfield repository without a utility-CSS
framework (D-01), and then — before a single line of app code is authored — read the Next.js
documentation that ships inside `node_modules` and reconcile it against the project's own stack
research.

Purpose: every other plan in this phase assumes a working `npm run build` / `npm run lint` gate and
assumes the Next.js API surface described in `.planning/research/STACK.md` is accurate. This plan
establishes the first and verifies the second. The project's own `.claude/CLAUDE.md` mandates that
the installed docs take precedence over any Next.js claim in the research; that reconciliation is a
task with acceptance criteria here, not a footnote.

Output: a building, linting, single-route Next.js project and a written reconciliation record.
</objective>
